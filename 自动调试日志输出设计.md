# 自动调试日志输出功能设计

## 功能概述

在断点触发时，自动捕获并输出详细的调试信息到日志文件，便于在离线环境中分析程序运行状态。

## 使用场景

### 场景1: 离线环境调试
- 在离线环境中运行程序
- 设置断点
- 程序运行到断点时自动输出调试信息到日志
- 后续查看日志文件分析问题

### 场景2: 生产环境问题排查
- 在测试环境复现生产问题
- 设置关键位置的断点
- 自动记录详细的运行状态
- 分析日志定位问题

### 场景3: 性能分析
- 记录方法执行时的变量状态
- 分析数据流转过程
- 识别性能瓶颈

## 实现方案

### 1. DebugLogCapture - 调试信息捕获器

```java
public class DebugLogCapture {
    /**
     * 捕获断点位置的调试信息
     */
    public static DebugLogInfo captureDebugInfo(StackFrame frame) {
        DebugLogInfo info = new DebugLogInfo();

        // 捕获基本信息
        info.setLocation(getLocation(frame));
        info.setThreadName(frame.thread().name());
        info.setTimestamp(System.currentTimeMillis());

        // 捕获方法参数
        if (settings.logMethodParameters) {
            info.setParameters(captureParameters(frame));
        }

        // 捕获局部变量
        if (settings.logLocalVariables) {
            info.setLocalVariables(captureLocalVariables(frame));
        }

        // 捕获this对象
        if (settings.logThisObject) {
            info.setThisObject(captureThisObject(frame));
        }

        // 捕获调用栈
        if (settings.logCallStack) {
            info.setCallStack(captureCallStack(frame));
        }

        return info;
    }

    /**
     * 捕获方法参数
     */
    private static Map<String, VariableInfo> captureParameters(StackFrame frame) {
        Map<String, VariableInfo> parameters = new LinkedHashMap<>();

        try {
            List<LocalVariable> variables = frame.visibleVariables();
            for (LocalVariable var : variables) {
                // 只捕获参数（不包括局部变量）
                if (var.isArgument()) {
                    Value value = frame.getValue(var);
                    VariableInfo varInfo = new VariableInfo();
                    varInfo.setName(var.name());
                    varInfo.setType(var.typeName());
                    varInfo.setValue(formatValue(value, var.name()));
                    parameters.put(var.name(), varInfo);
                }
            }
        } catch (Exception e) {
            LOG.error("Failed to capture parameters", e);
        }

        return parameters;
    }

    /**
     * 捕获局部变量
     */
    private static Map<String, VariableInfo> captureLocalVariables(StackFrame frame) {
        Map<String, VariableInfo> variables = new LinkedHashMap<>();

        try {
            List<LocalVariable> localVars = frame.visibleVariables();
            for (LocalVariable var : localVars) {
                // 只捕获局部变量（不包括参数）
                if (!var.isArgument()) {
                    Value value = frame.getValue(var);
                    VariableInfo varInfo = new VariableInfo();
                    varInfo.setName(var.name());
                    varInfo.setType(var.typeName());
                    varInfo.setValue(formatValue(value, var.name()));
                    variables.put(var.name(), varInfo);
                }
            }
        } catch (Exception e) {
            LOG.error("Failed to capture local variables", e);
        }

        return variables;
    }

    /**
     * 捕获this对象
     */
    private static ObjectInfo captureThisObject(StackFrame frame) {
        try {
            ObjectReference thisObject = frame.thisObject();
            if (thisObject != null) {
                ObjectInfo objInfo = new ObjectInfo();
                objInfo.setClassName(thisObject.referenceType().name());

                // 捕获对象字段
                Map<String, VariableInfo> fields = new LinkedHashMap<>();
                Map<Field, Value> fieldValues = thisObject.getValues(thisObject.referenceType().allFields());

                for (Map.Entry<Field, Value> entry : fieldValues.entrySet()) {
                    Field field = entry.getKey();
                    Value value = entry.getValue();

                    VariableInfo fieldInfo = new VariableInfo();
                    fieldInfo.setName(field.name());
                    fieldInfo.setType(field.typeName());
                    fieldInfo.setValue(formatValue(value, field.name()));
                    fields.put(field.name(), fieldInfo);
                }

                objInfo.setFields(fields);
                return objInfo;
            }
        } catch (Exception e) {
            LOG.error("Failed to capture this object", e);
        }

        return null;
    }

    /**
     * 格式化值（包括脱敏处理）
     */
    private static String formatValue(Value value, String fieldName) {
        if (value == null) {
            return "null";
        }

        String valueStr = value.toString();

        // 脱敏处理
        if (settings.maskSensitiveData && isSensitiveField(fieldName)) {
            return "******";
        }

        // 长度限制
        if (valueStr.length() > settings.maxVariableValueLength) {
            return valueStr.substring(0, settings.maxVariableValueLength) + "...";
        }

        return valueStr;
    }

    /**
     * 判断是否是敏感字段
     */
    private static boolean isSensitiveField(String fieldName) {
        String lowerName = fieldName.toLowerCase();
        for (String sensitive : settings.sensitiveFieldNames) {
            if (lowerName.contains(sensitive.toLowerCase())) {
                return true;
            }
        }
        return false;
    }
}
```

### 2. DebugLogFormatter - 日志格式化器

```java
public class DebugLogFormatter {
    private static final String SEPARATOR = "=".repeat(60);

    /**
     * 格式化调试信息为日志文本
     */
    public static String format(DebugLogInfo info) {
        StringBuilder log = new StringBuilder();

        // 头部
        log.append(SEPARATOR).append("\n");
        log.append("[断点触发] ").append(formatTimestamp(info.getTimestamp())).append("\n");
        log.append(SEPARATOR).append("\n");
        log.append("位置: ").append(info.getLocation()).append("\n");
        log.append("线程: ").append(info.getThreadName()).append("\n");
        log.append("调用栈深度: ").append(info.getCallStackDepth()).append("\n");
        log.append("\n");

        // 方法参数
        if (!info.getParameters().isEmpty()) {
            log.append("【方法参数】\n");
            for (VariableInfo var : info.getParameters().values()) {
                log.append("  ").append(var.getName());
                log.append(" (").append(var.getType()).append(")");
                log.append(" = ").append(var.getValue()).append("\n");
            }
            log.append("\n");
        }

        // 局部变量
        if (!info.getLocalVariables().isEmpty()) {
            log.append("【局部变量】\n");
            for (VariableInfo var : info.getLocalVariables().values()) {
                log.append("  ").append(var.getName());
                log.append(" (").append(var.getType()).append(")");
                log.append(" = ").append(var.getValue()).append("\n");
            }
            log.append("\n");
        }

        // this对象
        if (info.getThisObject() != null) {
            ObjectInfo obj = info.getThisObject();
            log.append("【this对象】\n");
            log.append("  类: ").append(obj.getClassName()).append("\n");
            log.append("  字段:\n");
            for (VariableInfo field : obj.getFields().values()) {
                log.append("    ").append(field.getName());
                log.append(" (").append(field.getType()).append(")");
                log.append(" = ").append(field.getValue()).append("\n");
            }
            log.append("\n");
        }

        // 调用栈
        if (!info.getCallStack().isEmpty()) {
            log.append("【调用栈】\n");
            for (int i = 0; i < info.getCallStack().size(); i++) {
                String frame = info.getCallStack().get(i);
                log.append("  [").append(i + 1).append("] ").append(frame);
                if (i == 0) {
                    log.append("  ← 当前位置");
                }
                log.append("\n");
            }
            log.append("\n");
        }

        log.append(SEPARATOR).append("\n\n");

        return log.toString();
    }
}
```

### 3. DebugLogWriter - 日志输出器

```java
public class DebugLogWriter {
    private static final Logger LOG = Logger.getInstance(DebugLogWriter.class);

    /**
     * 输出调试日志
     */
    public static void writeLog(DebugLogInfo info) {
        String logContent = DebugLogFormatter.format(info);

        // 输出到IDEA日志
        if (settings.outputToIdeaLog) {
            LOG.info(logContent);
        }

        // 输出到独立文件
        if (settings.outputToFile) {
            writeToFile(logContent);
        }
    }

    /**
     * 异步输出日志
     */
    public static void writeLogAsync(DebugLogInfo info) {
        if (settings.asyncLogging) {
            ApplicationManager.getApplication().executeOnPooledThread(() -> {
                writeLog(info);
            });
        } else {
            writeLog(info);
        }
    }

    /**
     * 写入文件
     */
    private static void writeToFile(String content) {
        try {
            File logDir = new File(settings.logOutputPath);
            if (!logDir.exists()) {
                logDir.mkdirs();
            }

            String fileName = "debug-log-" +
                new SimpleDateFormat("yyyyMMdd").format(new Date()) + ".txt";
            File logFile = new File(logDir, fileName);

            try (FileWriter writer = new FileWriter(logFile, true)) {
                writer.write(content);
                writer.flush();
            }
        } catch (IOException e) {
            LOG.error("Failed to write debug log to file", e);
        }
    }
}
```

### 4. 集成到DebuggerEventListener

```java
@Override
public void sessionPaused(@NotNull DebuggerSession session) {
    // ... 现有代码 ...

    // 自动日志输出
    if (settings.enableAutoLogging) {
        try {
            SuspendContext suspendContext = session.getSuspendContext();
            if (suspendContext != null) {
                StackFrame frame = suspendContext.getFrameProxy().getStackFrame();

                // 捕获调试信息
                DebugLogInfo logInfo = DebugLogCapture.captureDebugInfo(frame);

                // 异步输出日志
                DebugLogWriter.writeLogAsync(logInfo);
            }
        } catch (Exception e) {
            LOG.error("Failed to output debug log", e);
        }
    }
}
```

## 优势

1. **自动化** - 无需手动添加日志代码
2. **详细** - 捕获完整的运行时状态
3. **安全** - 自动脱敏敏感信息
4. **灵活** - 可配置输出内容和位置
5. **性能** - 异步输出不影响调试性能
6. **离线友好** - 日志文件可以带出离线环境分析

## 与现有功能的配合

1. **调用栈捕获** - 自动日志输出可以记录每个断点的详细状态

3. **AI分析** - 日志内容可以提供给AI分析
